# Factorial Calculator in Python

## Overview
This project contains a Python program that calculates the factorial of a number entered by the user.

## How It Works
- Takes an integer as input.
- Initializes the factorial to 1.
- Uses a `for` loop to multiply the numbers from 1 to the entered number.
- Prints the calculated factorial.

## How to Run
Run the `factorial.py` file using Python and enter a number when prompted.

## Example
**Input:** `5`

**Output:** `Factorial: 120`

## Learning Objective
To understand Python input, variables, loops, and multiplication through a simple factorial program.
